# Product icons

The seven marks used in the Products of Relevance section, in the colour they render on the page
(`#D1C4FF`, the page's `--purple-light-accessible` token).

| File | Product |
|---|---|
| `wolfram-one.svg` | Wolfram\|One |
| `ai-products.svg` | AI Products |
| `wolfram-system-modeler.svg` | Wolfram System Modeler |
| `quezzio.svg` | Quezzio |
| `wolfram-alpha.svg` | Wolfram\|Alpha |
| `wolfram-u.svg` | Wolfram U |
| `wolfram-etextbook-series.svg` | Wolfram eTextbook Series |

Each file is a 44 × 44 square with its glyph centred. The glyphs are sized optically, so all seven
read the same size when placed at the same width and height. Use them at equal dimensions and do
not crop or trim them.
